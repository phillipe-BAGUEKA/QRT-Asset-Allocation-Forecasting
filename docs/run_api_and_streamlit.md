# Running the QRT FastAPI and Streamlit Applications

The inference application uses two local processes:

```text
Browser -> Streamlit -> FastAPI / Uvicorn -> persisted QRT pipeline
```

FastAPI is the only component that loads the Joblib pipeline. Streamlit communicates with it over HTTP and never reads the model artifact directly.

## Prerequisites

Run all commands from the repository root. The following local files must exist:

```text
models/gradient_boosting_ret20_v1.joblib
models/gradient_boosting_ret20_v1.metadata.json
images/QRT-Brand-Master-Full-WO-HR.png
```

Raw training or test CSV files are not required for inference.

Activate the environment and install the declared dependencies:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Terminal 1 — Start FastAPI

Open a first PowerShell terminal at the repository root and run:

```powershell
.\.venv\Scripts\Activate.ps1
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Useful URLs:

| Resource | URL |
|---|---|
| API root | <http://127.0.0.1:8000> |
| Health | <http://127.0.0.1:8000/health> |
| Model information | <http://127.0.0.1:8000/model-info> |
| Swagger UI | <http://127.0.0.1:8000/docs> |
| ReDoc | <http://127.0.0.1:8000/redoc> |

The model and its metadata are loaded once during the FastAPI lifespan. `GET /health` only confirms that the API process responds. If the persisted resources cannot be loaded, model-dependent endpoints return HTTP `503` and the server logs contain the detailed startup error.

## Terminal 2 — Start Streamlit

Keep FastAPI running. Open a second PowerShell terminal at the repository root and run:

```powershell
.\.venv\Scripts\Activate.ps1
$env:QRT_API_BASE_URL="http://127.0.0.1:8000"
python -m streamlit run frontend/streamlit_app.py --server.port 8501
```

Open the frontend at <http://127.0.0.1:8501>.

The Streamlit application contains four pages:

- **Accueil** — project context, API status, and model summary;
- **Prédiction** — live single-row inference through `POST /predict`;
- **Modèle** — metadata retrieved from `GET /model-info`;
- **API** — architecture, endpoint inventory, and documentation links.

Both terminal processes must remain active while the application is used. Stop each process with `Ctrl+C` in its respective terminal.

## API configuration

`QRT_API_BASE_URL` controls which FastAPI instance Streamlit calls. If the variable is absent or empty, the frontend defaults to:

```text
http://127.0.0.1:8000
```

Set the variable before starting Streamlit when FastAPI uses another host or port.

## Troubleshooting

### The API is not running

Start Terminal 1 before using the prediction page. Confirm that <http://127.0.0.1:8000/health> returns `{"status":"healthy"}`.

### The Joblib model is missing

FastAPI remains responsive, but `/model-info` and `/predict` return HTTP `503`. Regenerate the validated local artifact with:

```powershell
python scripts/train_final_gradient_boosting.py
```

This command requires the authorized local training data and a clean Git worktree.

### The metadata JSON is missing or invalid

Ensure that `models/gradient_boosting_ret20_v1.metadata.json` exists and was generated by the final training script. Do not manually invent or alter model metadata.

### The QRT logo is missing

The frontend falls back to text and logs an explanatory error. Restore the original PNG at `images/QRT-Brand-Master-Full-WO-HR.png`; no copy or renamed variant is required.

### Commands were launched from the wrong directory

Return to the repository root—the directory containing `app/`, `frontend/`, `models/`, and `requirements.txt`—then run the commands again.

### Port 8000 is already occupied

Stop the other process or select another API port, for example:

```powershell
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8001
```

Then set `$env:QRT_API_BASE_URL="http://127.0.0.1:8001"` before starting Streamlit.

### Port 8501 is already occupied

Choose another frontend port:

```powershell
python -m streamlit run frontend/streamlit_app.py --server.port 8502
```

### The virtual environment is not active

Run `.\.venv\Scripts\Activate.ps1` from the repository root, or invoke the environment interpreter explicitly with `.\.venv\Scripts\python.exe`.

### `QRT_API_BASE_URL` is incorrect

Reset it in the Streamlit terminal and restart Streamlit:

```powershell
$env:QRT_API_BASE_URL="http://127.0.0.1:8000"
```

Do not include `/docs`, `/health`, or another route in the base URL.
